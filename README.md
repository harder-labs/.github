# Harder Labs on GitHub

This repository contains the [Harder Labs organization profile](https://github.com/harder-labs). GitHub displays [`profile/README.md`](profile/README.md) on the organization's public page; [`profile/banner.svg`](profile/banner.svg) supplies its visual header.

The company website at [harder.dev](https://harder.dev) describes the lab and its ventures. When updating this profile, keep the positioning and project summaries aligned with the site's [About page](https://harder.dev/about) and [project content](https://github.com/harder-labs/harder.dev/tree/main/src/content/projects).
